# Stage 4 Acceptance Checklist

Stage 4 — Technical Documentation is complete when:

- [x] system resource topology is documented,
- [x] Prefill and Decode lifecycles are documented,
- [x] compact request-state identifiers are mapped to readable names,
- [x] scheduler portfolio and final routing are documented,
- [x] final concurrent warm pipeline is explained separately,
- [x] scoring model used by the solver is documented,
- [x] public-vs-local experimental method is documented,
- [x] robustness/canary/final-submission discipline is documented,
- [x] terminology is centralized,
- [x] Markdown relative links pass repository validation.

Stage 5 should build on these documents rather than redefining the system model.
