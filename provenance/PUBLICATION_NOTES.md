# Publication Notes

This repository is a post-contest reconstruction, not a claim that the displayed Git commit history existed during the contest.

Publication principles:

1. Preserve exact public results separately from local diagnostics.
2. Mark the historical ~15595.199 starting value as approximate.
3. Do not infer hidden/system-test performance from the preserved 22 public cases.
4. Do not claim a final rank unless it has been independently verified for the exact handle.
5. Preserve the actual final resubmitted source and Stage 0 hashes.
6. Keep raw scratch archives outside the public repository.
7. Disclose AI-assisted development rather than presenting generated analysis as independently derived evidence.

The contest dashboard is linked from the root README; this repository focuses on the verified public score and engineering process rather than a rank claim.
