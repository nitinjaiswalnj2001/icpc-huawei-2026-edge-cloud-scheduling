# Figures

This directory contains lightweight, repository-ready figures generated from the curated experiment dataset.

| Figure | Source data | Purpose |
|---|---|---|
| `score_progression.svg` / `.png` | `../experiments/data/score_progression.csv` | Selected overall public-score milestones from the approximate historical baseline through FINAL CONCURRENT65. |
| `case4_warm_thresholds.svg` / `.png` | `../experiments/data/case4_threshold_curve.csv` | Comparison of non-concurrent and concurrent warm-start regimes on public case #4. |

The SVG files are used by the GitHub README. PNG copies are retained for report/presentation workflows that prefer raster assets.

The historical starting point in the score-progression figure is explicitly marked approximate; the later plotted milestones are exact public results.
