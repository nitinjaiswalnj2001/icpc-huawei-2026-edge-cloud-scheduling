# Stage 00 — Earliest Preserved Baseline Lineage

## Purpose

This folder preserves the earliest **exact C++ source files that survived into the final archive**. It is deliberately not labeled as the true original contest baseline.

Historical notes record an original public baseline of approximately **15,595.199**, but the exact source corresponding to that number was not recovered in the frozen archive. Rather than manufacture a baseline, this repository starts the code lineage from the earliest source artifacts that can be traced to the archived workspace.

## Files

### `nova_portfolio_16024_reference.cpp`

An early NOVA/portfolio reference recovered from the archived project baseline directory. The filename reflects the historical `16024` lineage, but this repository does **not** claim an exact reconstructed 22-case score for this file because the matching public vector was not frozen alongside it.

### `sprintk2_banked_16042_reference.cpp`

A later score-aware portfolio checkpoint using the SPRINT-K2 lineage. The historical experiment ledger records a Codeforces checkpoint of approximately **16,042.0524** for this bank.

## Why both are kept

Together these files show the transition from a general portfolio baseline toward more specialized routing before the exact 16,141.820688 control bank used by the later architecture experiments.

## Evidence status

- Source files: **exact archived artifacts**
- Original ~15,595 baseline source: **not recovered**
- NOVA `16024` exact 22-case vector: **not recovered**
- SPRINT-K2 `16042.0524`: **historical judge checkpoint recorded in the experiment ledger**
